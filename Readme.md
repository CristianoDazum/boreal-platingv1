# Boreal Plating

Site institucional bilíngue da Boreal Plating, desenvolvido em Astro + TypeScript.

## Status do projeto

Este projeto está em desenvolvimento e ainda passará por ajustes visuais, técnicos e de conteúdo antes da versão final.

## Estrutura atual

O site contempla páginas para:

- Home
- Quem Somos
- O Que Fazemos
- P&D
- ESG
- Certificações
- Fornecedores
- Carreiras
- Contato
- Versão em inglês

## Tecnologias

- Astro
- TypeScript
- HTML5
- CSS
- JavaScript

## Observação

Esta versão ainda não deve ser considerada definitiva. Novas alterações serão realizadas até a aprovação final do projeto.
